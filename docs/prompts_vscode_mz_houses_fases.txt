POLÍTICAS DE RECURSO

Criar uma estrutura clara dentro de `access_json.features`.

Modelo conceitual:

{
  "features": {
    "stash": {
      "mode": "inherit"
    },
    "wardrobe": {
      "mode": "inherit"
    },
    "garage": {
      "mode": "inherit"
    }
  }
}

Modos recomendados:

- `inherit`: herda a autorização normal da propriedade;
- `disabled`: recurso desativado;
- `owner`: somente owner;
- `keys`: owner e portadores de chave;
- `rules`: usa regras próprias de gang/job/grade/duty;
- `public`: qualquer jogador dentro da propriedade;
- `admin`: somente admin.

Adapte à estrutura definida no plano e ao código real.

Não invente modos desnecessários.

Gang/job:

- recursos usam `inherit` por padrão;
- permitir grade mínima diferente por recurso;
- permitir `requireDuty` quando aplicável ao job.

Interior público:

- entrada pública não torna automaticamente stash, wardrobe ou garagem públicos;

Interior administrativo:
